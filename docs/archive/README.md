## What to use instead

- Current sprint status → `TASK_QUEUE.md` (internal, gitignored)
- Release history → `RELEASES.md` (root)
- Architecture decisions → `ARCHITECTURE.md` (root)
- Solution patterns → `docs/solutions/` (active institutional knowledge)
