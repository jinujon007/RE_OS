## HIGH — Must Fix

### H1. `_READ_ONLY_PATHS` v1 aliases incomplete
**File:** `dashboard/state.py:266–296`  
**Detail:** 24 paths exist in the `/api/` set but are missing their `/api/v1/` equivalents. The auth middleware checks `_READ_ONLY_PATHS` against the request path (`/api/v1/...`). Missing v1 paths cause authenticated requests to those endpoints to fail with 401 when an API key is configured.
**Affected paths missing v1 alias:** `/api/competitive/pulse`, `/api/portfolio`, `/api/portfolio/summary`, `/api/pr/mentions`, `/api/optimizer/report`, `/api/digest/weekly`, `/api/digest/monthly`, `/api/llm/quota`, `/api/corridor/score`, `/api/ops/slo`, `/api/ops/kill-criteria` (half-present), `/optimizer` (non-api)

### H2. `_READ_ONLY_PREFIXES` missing critical v1 aliases
**File:** `dashboard/state.py:298–306`  
**Detail:** 5 route prefixes are missing their `/api/v1/` variants: `/api/content/`, `/api/process-audit/`, `/api/shareholders/`, `/api/govt/`, `/api/competitive/`, `/api/portfolio/`, `/api/pr/`, `/api/optimizer/`, `/api/llm/`. Requests to `/api/v1/content/generate` will fail auth check when API key is set.

### H3. `_err_resp` fragile type annotation
**File:** `dashboard/state.py:58`  
**Detail:** Uses `"Request | None"` as a string-literal type annotation without `from __future__ import annotations`. This works in Python 3.10+ runtime but breaks static type analysis and IDE completions. Should be `from __future__ import annotations` or `Optional[Request]`.

### H4. Legacy redirect drops query parameters
**File:** `dashboard/app_fastapi.py:237–242`  
**Detail:** `RedirectResponse(url=f"/api/v1/{path}")` does not preserve `?query=param` from the original request. Any client calling `/api/endpoint?param=value` will lose all query parameters. Starlette `Request` object exposes `request.url.query` which must be appended.

### H5. Test isolation relies on cache-busting workaround
**File:** `tests/test_gate106.py:16–20`, `tests/test_dashboard_routes.py` (multiple)  
**Detail:** The `_reset_api_keys()` + monkeypatch pattern is a bandage over the root cause: `_ensure_api_keys` caches the first-seen `_API_KEY` globally with no mechanism to reload. This coupling means:
1. Test order dependency (401 tests must be designed around conflicting global state)
2. Impossible to parallelize test execution
3. Future tests will silently break if order changes

## MEDIUM — Should Fix

### M1. Missing v1 paths in `_ADMIN_PATHS` and `_WRITE_PATHS`
**File:** `dashboard/state.py:250–262`  
**Detail:** `/api/v1/audit/log` has no `/api/v1/` variant in `_ADMIN_PATHS`. While `_READ_ONLY_PREFIXES` covers `/api/v1/evaluate/`, the exact paths `/api/v1/evaluate` and `/api/v1/board/session` in `_WRITE_PATHS` are exact matches used by the middleware's `path in _WRITE_PATHS` check — but the actual request path is `/api/v1/evaluate` (no trailing slash), which works. However `/api/v1/audit/log` is missing entirely.

### M2. Non-unified error responses remain
**File:** All routers (3 remaining instances)  
**Detail:** 3 `JSONResponse({"error":...})` calls were intentionally skipped during T-1219 because they carried extra fields beyond `error`. These should either use `_err_resp` with a composite response or extend `ErrorResponse`.

### M3. ETag uses MD5 (FIPS compliance risk)
**File:** `utils/etag.py:14`  
**Detail:** `hashlib.md5()` raises `ValueError` in FIPS-enabled Python environments. Use `usedforsecurity=False` param: `hashlib.md5(raw.encode(), usedforsecurity=False)`.

### M4. Default rate limit headers misleading
**File:** `dashboard/app_fastapi.py:103–106`  
**Detail:** Non-rate-limited endpoints get `X-RateLimit-Limit: 1000, X-RateLimit-Remaining: 1000, X-RateLimit-Reset: 0`. This implies a rate limit of 1000 exists. Better to omit these headers entirely on non-rate-limited endpoints, or set them to indicate no limit (`X-RateLimit-Limit: 0` is standard for unlimited).

### M5. ETag applied to only 5 of 10+ read-heavy endpoints
**Detail:** `/api/v1/db/state`, `/api/v1/intel/search`, `/api/v1/opportunity/queue`, `/api/v1/memory/explorer`, `/api/v1/scheduler/health` are all GET endpoints that could benefit from ETag caching.

### M6. `docs/api-v1.json` is an empty stub
**Detail:** Placeholder JSON with empty `paths`. Should be generated from the live FastAPI OpenAPI spec. Without this, consumers cannot rely on the frozen API contract.

### M7. No canonical `docs_url` generation for ErrorResponse
**Detail:** Each router has a tag ("Health", "Data", etc.) passed to `_err_resp`. The `docs_url` is built as `/docs#tag/{tag}` which may not match the actual OpenAPI tag anchor generated by FastAPI.

### M8. Redirect handler passes `None` as request — request_id lost
**File:** `dashboard/app_fastapi.py:241`  
**Detail:** `_err_resp("not_found", None, 404, "Legacy")` — passing `None` as request means any error from legacy redirects will have empty `request_id`.
